PETA FRONTEND DAN BACKEND - KAMPUSKOLAB
=======================================

Nomor baris di bawah merujuk ke isi file saat peta ini dibuat. Baris kosong
ikut dihitung; nomor dapat berubah setelah file diedit.

STRUKTUR UTAMA
--------------

backend/
  config/       Konfigurasi backend.
  controllers/  Request, validasi, database, dan alur bisnis.
  core/         Bootstrap, helper, dan renderer view.

frontend/
  views/        Template HTML/PHP untuk tampilan.

database/ berisi schema dan data awal. storage/ menyimpan file privat di luar
web root. Folder public/ di root adalah web root Apache. Folder backend/ tidak
diekspos langsung oleh web server.
